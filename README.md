## Возможности

- Автогенерация случайных значений (0-30) каждую секунду
- Переключение режима: номер канала / число потерь
- Выбор активного канала (синяя рамка)
- Цвет кнопки зависит от значения:
  - 0 → зелёный
  - 1-10 → жёлтый
  - больше 10 → красный
