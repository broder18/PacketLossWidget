# Packet Loss Widget

Виджеты для отображения потери пакетов на 9 каналах.

## Виджеты

- **CircleAntennaWidget** - кнопки по кругу
- **VerticalAntennaWidget** - кнопки вертикально

## Возможности

- Автогенерация случайных значений (0-30) каждую секунду
- Переключение режима: номер канала / число потерь
- Выбор активного канала (синяя рамка)
- Цвет кнопки зависит от значения:
  - 0 → зелёный
  - 1-10 → жёлтый
  - больше 10 → красный
